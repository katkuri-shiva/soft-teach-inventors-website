# Soft Teach Inventors Educational Website

## Overview
Soft Teach Inventors is a responsive educational website developed using ASP.NET MVC, HTML5, CSS3, Bootstrap, and JavaScript.

## Features
* Home Page
* About Page
* Books Page
* Programs Page
* Technology Page
* Gallery Page
* Contact Page
* Responsive Design
* Interactive User Interface

## Technologies Used
* ASP.NET MVC
* C#
* HTML5
* CSS3
* Bootstrap
* JavaScript
